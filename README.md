# DORKAM Designs

A modern, responsive fashion design website created for **DORKAM Designs**, a fashion brand focused on African-inspired clothing, women's fashion, girls' fashion, and custom designs.

The website provides visitors with an attractive way to explore DORKAM Designs, learn about the brand, view fashion designs, and get in touch for custom fashion services.

---

## 📌 Project Overview

DORKAM Designs is a fashion design website designed to showcase creativity, African culture, elegance, and modern fashion.

The website contains four main pages:

- Home
- About Us
- Gallery
- Contact

The design uses a clean and modern interface with subtle animations, responsive layouts, fashion-focused imagery, and a consistent brand color scheme.

---

## 🌐 Website Pages

### 1. Home Page

The Home page introduces visitors to DORKAM Designs.

It includes:

- Navigation bar
- Hero section
- Welcome message
- Fashion carousel
- Featured fashion content
- Fashion category cards
- African Wear section
- Women's Fashion section
- Girls' Fashion section
- Custom Designs section
- Design process
- Call-to-action section
- Footer

The carousel allows visitors to browse featured fashion designs.

---

### 2. About Us Page

The About Us page introduces visitors to DORKAM Designs and explains the brand's approach to fashion.

It can include:

- Company introduction
- Brand story
- Mission
- Vision
- Fashion philosophy
- Values
- What makes DORKAM Designs unique
- Call-to-action
- Footer

The page is designed to help visitors understand the identity and purpose of the brand.

---

### 3. Gallery Page

The Gallery is the main fashion portfolio section of the website.

It is designed specifically to showcase DORKAM Designs' work.

Features include:

- Featured fashion design
- Fashion design gallery
- African Wear category
- Women's Fashion category
- Girls' Fashion category
- Custom Designs category
- Design filtering
- Hover effects
- Design titles
- Design categories
- Image lightbox
- "View Design" functionality
- Custom design call-to-action

Visitors can filter designs according to different fashion categories.

They can also click on a design to view a larger version of the image.

---

### 4. Contact Page

The Contact page allows potential customers to get in touch with DORKAM Designs.

The contact form includes:

- Name
- Phone number
- Service required
- Estimated budget
- Message/details

The page also provides contact information and encourages visitors to discuss their fashion requirements.

---

## 🎨 Design Theme

The website uses a consistent visual theme throughout all pages.

### Main Colors

| Color | Hex Code | Usage |
|---|---|---|
| Green | `#59b82a` | Primary brand color |
| Dark Green | `#3d8f1d` | Hover states and accents |
| Lime | `#d9ed00` | Highlights and buttons |
| Charcoal | `#414141` | Navigation and dark sections |
| Dark | `#303030` | Dark backgrounds |
| White | `#ffffff` | Main backgrounds |
| Light | `#f5f7f4` | Section backgrounds |
| Text Gray | `#626262` | Paragraph text |

The combination gives the website a modern, fresh and fashion-oriented appearance while maintaining a consistent identity.
